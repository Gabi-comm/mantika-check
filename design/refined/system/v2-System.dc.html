Accessibility specification

  1. Text 14px minimum, 17px mobile body; no text lighter than #4B5563
  2. Targets 48px mobile (56 primary), 40px web with 8px spacing
  3. 2px gold focus ring with 2px offset, visible on ink and paper
  4. Status always icon + word; colour third
  5. Layouts reflow at 320px and 200% zoom; labels wrap, never truncate
  6. Strings sized for Filipino at +35% length
  7. Motion ≤ 200ms, none under reduced motion
