# MANTIKA CHECK branding (concept C, Spectrum Check)

| File | Use |
|---|---|
| `mantika-check-mark.svg` | Primary symbol, colour |
| `mantika-check-mark-mono.svg` | One colour (ink) |
| `mantika-check-mark-reversed.svg` | Symbol on Canopy Green |
| `mantika-check-app-icon.svg` | App icon tile |
| `mantika-check-favicon.svg` | 16 to 32px, simplified single arc |
| `mantika-check-logo-horizontal.svg` | Navbar / slide lockup |
| `mantika-check-logo-horizontal-reversed.svg` | Lockup on dark |

Construction: three ring segments on a 64 unit grid (r 21, stroke 9, 6 degree gaps, 80 degree opening at the right) around a 12 unit sample square.
The three segments use brand greens only; they never represent strip result colours.
Wordmark uses Plus Jakarta Sans as live text; convert to outlines before print production.
This is an original design concept. No trademark search has been performed.
